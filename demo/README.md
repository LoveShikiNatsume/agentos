# 可验证交付物

本目录提供 AgentOS Runtime 的可运行、可复现、可部署成果。全部材料按运行环境的要求由低到高划分为四个层次，每一层给出运行入口、所需环境、归档结果的位置以及结果所能支持的结论范围。源代码位于 `src/`，实验的原始记录位于 `tests/测试及验证材料/`，本目录不重复存放。

## 1 组成

| 层次 | 目录 | 运行环境 | 验证内容 | 对应的赛题要求 |
| --- | --- | --- | --- | --- |
| 一 | [01-离线功能演示](01-离线功能演示/) | 通用 Linux，Python 3.11 及以上；不需要模型凭据 | 任务依赖执行、按任务选择上下文、单分支故障隔离、重试恢复、事件记录 | 多 Agent 任务调度；执行容错；上下文管理 |
| 二 | [02-国产系统部署](02-国产系统部署/) | Docker | 在 openEuler 24.03 LTS 与 openKylin 容器内完成构建、安装与全量回归测试；在 openEuler 容器内验证 cgroup v2 资源控制 | 基于国内主流开源操作系统开发 |
| 三 | [03-真实模型场景](03-真实模型场景/) | 云端模型接口凭据或本地 vLLM 服务 | 真实模型接口下的功能演示、经 LangGraph 接入的仓库审阅、软件工程场景与工作台 | 复杂多 Agent 应用场景；Agent 间通信 |
| 四 | [04-内核通路](04-内核通路/) | 安装指定内核的 openEuler 环境，root 权限 | 基于 sched_ext 的调度器对 Agent Worker 的接管、分级调度与回退 | 执行抽象与操作系统资源的关系；资源感知调度 |

第一层可在任意满足 Python 版本要求的 Linux 环境中直接运行；第二层至第四层对环境的要求逐级提高，无法满足运行条件时，可查阅各层说明中列出的归档结果。

## 2 环境准备

除第二层在容器内完成安装外，其余各层均在仓库根目录创建虚拟环境并安装本项目：

```bash
python3 -m venv .venv
.venv/bin/python -m pip install -e "./src[dev,app,langgraph]"
```

依赖项、锁文件的使用方式与原生组件的构建方法见根目录 `README.md`。

## 3 运行入口

| 层次 | 命令 |
| --- | --- |
| 一 | `bash demo/01-离线功能演示/run_offline_validation.sh` |
| 二 | `bash src/scripts/openeuler-verify.sh` |
| 三 | `.venv/bin/agentctl finals-demo --backend deepseek --output demo/output/finals_deepseek` |
| 四 | `make -C src/native/sched_ext KERNEL_SRC=<内核源码路径> all`，随后依次执行各验证脚本 |

各命令的参数、前置条件与输出格式见对应目录的说明。本地运行产生的输出统一写入 `demo/output/`，该目录已被 Git 忽略。

## 4 结论范围

四个层次所支持的结论相互独立，不可相互替代：

- 第一层使用 mock 后端和合成输入，说明功能链路的正确性，不涉及模型质量与性能。
- 第二层在容器内完成，说明本项目对相应发行版用户空间的适配，不涉及该发行版内核上的调度能力。
- 第三层的结果与所用模型、日期和批次相关，引用时须连同对应的元数据。
- 第四层的结果限定于指定内核与 partial mode 下显式绑定的 Agent Worker。
