# 测试及验证材料

本目录存放支撑项目功能、性能与技术结论的固定输入、原始记录与实验结果。

## 1 组成

| 目录 | 内容 |
| --- | --- |
| `fixtures/` | 固定的验证输入，供 sched_ext 校验器相关测试使用 |
| `evidence/` | 早期实验批次的原始记录 |
| `results/` | 按实验整理的结果，含汇总、原始数据、事件流与运行日志 |

## 2 实验结果

`results/` 下各目录对应一项实验或验证：

| 目录 | 日期 | 内容 |
| --- | --- | --- |
| `swe_bench_verified_30/` | 2026-07-09 | SWE-bench Verified 30 个任务，四种上层框架接入运行时前后的 Token 用量、缓存命中与故障恢复；含任务清单、逐任务结果与运行元数据 |
| `framework_benchmark_4fw_real/` | — | 四种框架的试运行，共 10 个任务，含汇总与逐任务数据 |
| `workload_matrix_deepseek_real/` | 2026-06-20 | DeepSeek 接口下 AI 推理、编译、压缩、网络四类负载的基线与运行时对照，含事件流 |
| `ppt_data/` | — | 消融、通信开销与故障传播实验的汇总表及原始运行记录 |
| `defense/` | — | 模拟缓存后端下的四类负载压力矩阵、事件流与事件面板 |
| `feedback_loop_bundle/` | — | 运行时资源反馈回路的事件、时间线与消融汇总 |
| `kernel_probe/` | 2026-07-03 | openEuler 24.03 LTS 容器内 cgroup v2 资源控制、PSI 采样与 pinned BPF map 读写的验证 |

## 3 早期记录

`evidence/` 保存八份早期的原始记录，内容未经改动：正式实验与增强实验各两个批次、一份调度基准、一份云端缓存汇总，以及 vLLM 缓存压力测试的原始日志与汇总。

## 4 复现

实验与验证脚本位于 `src/scripts/`，各脚本的参数见其帮助信息。重新运行时应将输出写入 `results/generated/`，该目录已被 Git 忽略，不会覆盖已归档的结果。依赖特定内核或真实模型接口的实验，其运行条件见 [`demo/README.md`](../../demo/README.md)。

## 5 结果的引用

各批次结果所用的模型、后端、日期与 Token 来源记录在对应目录的元数据中，引用结果时应一并注明。使用 mock 或模拟缓存后端的结果仅用于功能验证，不构成性能结论；四框架对比实验统计的是多 Agent 工作流的执行指标，不等同于 SWE-bench 官方的补丁通过率。
